## 轴

**对参考的取舍程度。** 参考是 stylekit 的 neo-brutalist showcase，最显眼的特征是**酸绿满屏当底色**。

- **硬派**：参考照单全收——酸绿当底、4px 黑框、8px 硬投影、等宽字、洋红与青当强调。
- **取气**：把「酸绿当底」这一条拿掉，只留粗黑线、硬投影、直角、巨标题这副骨架，底色换回品牌自己的 `#E5E5E5`，酸绿降级成唯一的强调点。

用户对取气的反应，直接回答「那片酸绿到底是不是你要的」。

## 渲染约定

- 全部用产品里的真实文案与真实常量（15 分钟自动存档 / 20 份历史 / 300 字上限），无占位文字。
- 参考里的绝对 px 先除以字号转成 em；容器宽度是唯一保留绝对值的地方。
- 中文标题字距 0（现站的 `-0.02em` 两版都改掉）；正文行高 1.85–1.9。
- 每个数值的出处（量得 / 看图估的 / 我们定的）在样张里的表格中列明。
- 只学版式与气质，没有搬参考的 logo、字体文件、图片或成段文案。
