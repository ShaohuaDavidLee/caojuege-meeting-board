## 决定

**现有的草诀歌风格一个字不动，在它之上新增一套可切换的「硬派」皮肤。**

- **现在（classic）** —— 基线。样张里那一列照 `src/index.css` 渲染：`#E5E5E5` 底、1px 发丝线、无投影、直角、衬线标题配 Inter。**这一列是对照组，不是提案。**
- **硬派（hard）** —— 新增。参考 stylekit neo-brutalist：酸绿当底、4px 黑框、8px 硬投影、等宽字当工具字体、洋红与青当强调。

## 硬约束

> 硬派只准换 CSS 变量。不改 DOM 结构，不改类名语义，不写按主题分支的渲染。

结构（栅格、1280px 容器、字号阶梯、80px 顶栏、320px 侧栏、280px 便签、0.2em 大写字距）两套共用，硬派一处没动。样张里的出处表按「结构 / 皮肤」分成两段，逐条标了来源：量得 / 看图估的 / 我们定的。

## 渲染约定

- 全部用产品里的真实文案；现状值全部量自 `src/index.css` 与组件源码。
- 参考里的绝对 px 先除以字号转成 em；容器宽度是唯一保留绝对值的地方。
- 硬派的中文标题字距 0、正文行高 1.9；不做描边空心字（中文笔画多，描边糊字腔），改用反白色块。
- 只学版式与气质，没有搬参考的 logo、字体文件、图片或成段文案。
